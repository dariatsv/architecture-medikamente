1. Отсутствие централизованного хранилища данных
    - Данные хранятся в различных файлах (Excel, PDF, JPG) без контроля версий и централизованного управления
    - Нет единого подхода к аудиту доступа к данным

2. Отсутствие механизмов контроля доступа (RBAC, ABAC)
    - Любой сотрудник, имеющий доступ к файлам, может просматривать и изменять конфиденциальную информацию
    - Отсутствуют разграничения доступа на уровне ролей пользователей

3. Хранение конфиденциальных данных в открытом виде
    - Медицинские карты, данные пациентов, результаты анализов хранятся без шифрования
    - Доступ к этим данным осуществляется без двухфакторной аутентификации

4. Отсутствие автоматизированного аудита действий пользователей
    - Нет системы логирования и отслеживания действий пользователей при работе с данными
    - В случае утечки невозможно определить источник компрометации информации

5. Неуправляемые потоки данных между системами
    - Передача данных между 1С, Excel и внутренними системами не контролируется
    - Нет механизмов контроля API-запросов и фильтрации конфиденциальных данных

6. Несоответствие требованиям законодательства РФ
    - Хранение и обработка персональных данных не соответствуют ФЗ-152 «О персональных данных»
    - Нет механизмов защиты PII (личной информации клиентов), что несёт репутационные и финансовые риски

7. Отсутствие механизмов тэгирования данных
    - Нет системы классификации данных по уровням конфиденциальности
    - Нет автоматизированной проверки обработки чувствительных данных

8. Неэффективная интеграция с лабораториями
    - Взаимодействие с лабораториями происходит вручную, что увеличивает вероятность ошибок
    - Нет стандартных API-контрактов для безопасного обмена медицинской информацией

9. Риски при масштабировании системы
    - Увеличение количества филиалов приведёт к усложнению работы с данными
    - Децентрализованное хранение данных затруднит администрирование и защиту информации

Рекомендации:
- Внедрить единую систему управления данными (DWH, Data Lake) с разграничением прав доступа
- Реализовать RBAC/ABAC для контроля доступа сотрудников
- Настроить автоматизированное шифрование конфиденциальных данных
- Ввести систему аудита и логирования действий пользователей
- Обеспечить соответствие требованиям ФЗ-152, внедрить механизмы защиты PII
- Разработать API-контракты для безопасной интеграции с лабораториями
- Ввести механизмы тэгирования данных и автоматизированную проверку обработки чувствительных данных
